HOW TO PLAY

💻 Desktop & Laptop Controls

  • A / Left Arrow: Switch to Left Lane
  • D / Right Arrow: Switch to Right Lane
  • W / Up Arrow / Space: Jump over low barriers
  • S / Down Arrow: Slide under high signals & gates
  • Escape / P: Pause or Resume Game

📱 Mobile & Tablet Controls

  • Swipe Left / Right: Change Lanes
  • Swipe Up: Jump
  • Swipe Down: Slide
  • Touch Buttons: Can be toggled anytime in Settings!

⚡ Power-Ups Guide

  • 🧲 Coin Magnet: Pulls coins from all 3 lanes automatically.
  • ⭐ 2x Multiplier: Doubles all score points earned.
  • 👟 Jump Boost: Super-charged leaps to clear tall trains!
  • 🛡️ Energy Shield: Absorbs 1 fatal obstacle crash safely.
  • 🚀 Nitro Boost: Blasts forward at turbo speed with invulnerability.

2. How to Run Locally & Host Online

  • Local Execution: Save this file as index.html. Open it directly in any modern browser, or serve via npx serve . or python -m http.server 8080.
  • Static Hosting: Upload index.html to Cloudflare Pages, Vercel, Netlify, GitHub Pages, AWS S3, or standard cPanel hosting.
  • GoDaddy / Website Builder Note: Standard GoDaddy shared cPanel hosting supports uploading raw HTML files directly. However, GoDaddy Website Builder embeds custom code inside sandboxed iframes—host the game file on a dedicated subdomain (e.g., play.yourdomain.com) or CDN and embed via the responsive iframe snippet below.

4. Copyright & Google AdSense Readiness

All 3D models, procedural textures, synthesized Web Audio effects, UI icons, and code in Metro Rush 3D are 100% original and clean of third-party copyrighted logos or audio. No AdSense tags are placed inside the game canvas/iframe. Website owners applying for Google AdSense must place ad units on the surrounding portal page with clear visual separation (at least 150px recommended) from the game container to prevent accidental clicks and comply with Google Publisher Policies.

5. Completed Verification & Known Limitations

Verified Systems: 3-lane lateral interpolation, buffered keyboard & touch swipe detection, procedural track recycling, guaranteed single-lane escape path validation, AABB collision detection with height/slide clearance, 5 timed power-ups, Web Audio synthesizer with autoplay unlock, and memory-safe object pooling.

Known Platform Limitations: Physical hardware testing on every specific iPhone/Android handset remains unverified outside browser viewport/touch simulation; iOS Safari does not support the standard Fullscreen API on inner elements, so the game gracefully expands to fill the viewport when native fullscreen is unavailable.
